# Meu Portfólio

## Como rodar
1. `npm install`
2. `npm run dev` → abre em http://localhost:5173

## Como adicionar um projeto novo
Edite só o arquivo `src/data/projects.js` — adicione um objeto novo no array.
Não precisa mexer em nenhum componente.

## Como fazer deploy
1. Suba este código num repositório no GitHub
2. Crie conta na Vercel (vercel.com) e conecte o repositório
3. A Vercel detecta que é Vite/React automaticamente e faz o deploy

## Próximos passos sugeridos

- Adicionar imagens dos projetos (pode criar uma pasta `src/assets/`)
